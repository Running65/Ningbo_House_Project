## 二、布局要点

1. **视线动线**：左上（各区对比）→ 中部（地图主视觉）→ 右侧（分布与相关性），符合"结论 → 空间 → 深入分析"的叙事顺序
2. **主次分明**：地图占中间最大区块（约 40% 宽），柱状图次之，热力图最小（专业但非主角）
3. **KPI 卡**：顶部通栏 4 张，大数字 + 小标签，与下方图表色彩呼应
4. **配色方案（深色商务风初稿）**
   - 背景：深蓝 `#0f1c3f` / 卡片 `#16264d`
   - 主色：金色 `#f6c344`（均价）、青色 `#37c6ff`（数量）
   - 辅助：橙色 `#ff9c6e`（警示/高亮）、灰蓝 `#8ea0c4`（次要文字）
   - 原则：全大屏不超过 4 种主色，图 1/4/6 同用一套区域配色保持一致
5. **标题栏**：大标题左侧，右侧放数据更新日期；用 CSS 渐变描边做科技感分割线

| 事项 | 方案 |
