# 数据分析思路文档（成员B · 第一周交付物）

> 撰写人：成员 B（数据清洗与分析工程师）
> 项目方向：方向 C —— 宁波市二手房市场价格洞察
> 数据基础：贝壳找房宁波站 1195 条挂牌房源（2026-11-25 采集，覆盖 11 个区县市）

## 一、核心研究问题

1.宁波市各行政区（区县市）的二手房**单价水平差异有多大**？哪些区域是价格高地/洼地？
2.房源**总价呈怎样的分布**？主流成交（挂牌）区间集中在哪一段？
3.**面积与单价之间是否存在关系**？小面积是否意味着更高单价？
4.各区域内部的**房价离散程度**如何？哪些区价格透明、哪些区分化严重？
5.综合价格、面积、户型等因素，如何定义并筛选**高性价比房源**？

## 二、分析维度

| 维度 | 关键字段 | 分析内容 |
|---|---|---|
| 区域 | district、unit_price | 各区平均/中位单价、价格排名 |
| 价格 | total_price | 总价分布、价格区间占比 |
| 面积 | area、unit_price | 面积区间划分、面积-单价相关性 |
| 户型 | rooms | 各户型数量与单价差异 |
| 楼层 | floor | 低/中/高楼层单价对比（数据允许时） |

## 三、分析流程（对应六周计划）

1. **数据清洗（第3周）**：`clean.py` —— 去重（以房源链接为主键）、缺失值处理（楼层缺失保留）、正则提取面积/单价/关注数数值、统一单位与字段类型，输出 `clean_data.csv`。
2. **统计分析（第4周）**：`analysis.py` —— 各区平均单价、总价区间占比、面积-单价相关系数（Pearson）、各区箱线图统计量。
3. **性价比筛选（第4周）**：初步规则——单价低于所在区中位数、面积不低于全市中位数、总价可负担（如 ≤200 万），三条规则量化为综合得分后排序。
4. **结论提炼（第5周）**：核对图表数据一致性，提炼 3–5 条有数据支撑的结论，撰写报告分析部分。

## 四、预期结论形式（示例框架，具体以清洗后数据为准）

- 「宁波二手房挂牌单价最高的区是 ××（约 ×× 元/㎡），最低的是 ××（约 ×× 元/㎡），相差约 ×× 倍」；
- 「总价 80–150 万区间的房源占比最高，约 ××%」；
- 「面积与单价的相关系数约 ××，呈弱/强负相关」；
- 按性价比规则筛选出 ×× 套候选房源，集中在 ×× 区。

## 五、与组内其他成员的接口

- 向成员 C 提供各图表的统计结果（CSV/JSON），字段名按《数据字段设计表》标准字段对齐；
- 数据问题（缺字段、格式错误）反馈给成员 A，由其核查采集端原因；
- 所有统计均基于 `clean_data.csv`，保证图表数据与原始数据可核对。
