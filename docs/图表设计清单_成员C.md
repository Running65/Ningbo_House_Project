## 图 1：各行政区平均单价柱状图（Bar）

| 项目 | 说明 |
|---|---|
| 图表目的 | 回答"宁波哪个区县房价最高/最低"，是全大屏的核心对比图 |
| 横轴（X） | 行政区，按平均单价降序排列 |
| 纵轴（Y） | 单价(元/平) 均值，保留整数 |
| 所需字段 | 行政区、单价(元/平) |
| 清洗要求 | ① 行政区名称以 B 的清洗结果为准（统一为「鄞州区」这类全称）；② 单价(元/平) 去千位逗号转数值（B 第 3 周统一处理）；③ 剔除单价缺失或为 0 的记录 |
| 交互组件 | Tooltip 显示均价+房源数；DataZoom 当区县较多时横向缩放 |
| 放置位置 | 大屏左侧第一列，最显眼位置 |

## 图 2：总价区间占比饼图（Pie）

| 项目 | 说明 |
|---|---|
| 图表目的 | 回答"市场上哪种总价的房子最多"，展示房源价格结构 |
| 分组 | 总价(万) 分箱：<100万 / 100-150万 / 150-200万 / 200-300万 / 300-500万 / >500万（分箱边界第 3 周按 B 的数据分布微调，B 建议过 ≤80 / 80–150 / 150–300 / >300 万） |
| 所需字段 | 总价(万) |
| 清洗要求 | ① 总价(万) 已是数值型；② 剔除缺失值；③ 分箱前用 describe() 检查极端值（B 质量报告：最小 19 万、最大 1799 万，存在高价长尾） |
| 交互组件 | Tooltip 显示占比百分比；扇区可点击高亮（selected mode） |
| 放置位置 | 大屏第二列上部 |

## 图 3：面积与单价散点图（Scatter）

| 项目 | 说明 |
|---|---|
| 图表目的 | 回答"是不是面积越大单价越便宜"（学区房/改善房规律） |
| 横轴（X） | 面积（㎡） |
| 纵轴（Y） | 单价(元/平)（元/㎡） |
| 所需字段 | 面积、单价(元/平)（可选行政区做颜色系列） |
| 清洗要求 | ① 面积去「平米」转数值型，剔除 0 或极端值（如 >500㎡ 需核实）；② 与图 1 共用单价(元/平) 清洗规则 |
| 交互组件 | Tooltip 显示小区名+具体面积单价；visualMap 按单价映射颜色 |
| 放置位置 | 大屏第二列下部 |

## 图 4：各行政区单价箱线图（Boxplot）

| 项目 | 说明 |
|---|---|
| 图表目的 | 展示各区房价的分布和离散程度（均值低不代表没有高端盘） |
| 横轴（X） | 行政区 |
| 纵轴（Y） | 单价(元/平) 分布（上须、四分位、中位数、下须、离群点） |
| 所需字段 | 行政区、单价(元/平) |
| 清洗要求 | ① 每区样本量须足够（如 ≥30 条），样本太少的区合并或标注（B 质量报告：11 区县，宁海县仅 38 条、象山县 77 条，需留意）；② 离群点保留但可点击 Tooltip 查看 |
| 交互组件 | Tooltip 显示四分位数 |
| 放置位置 | 大屏第三列上部 |

## 图 5：数值变量相关性热力图（Heatmap）

| 项目 | 说明 |
|---|---|
| 图表目的 | 一眼看懂总价、单价、面积之间两两相关性，为筛选模型提供依据 |
| 内容 | 总价(万) × 单价(元/平) × 面积 的 3×3 相关系数矩阵（Pearson） |
| 所需字段 | 总价(万)、单价(元/平)、面积 |
| 清洗要求 | ① 三个字段均为数值型（面积去「平米」、单价去千位逗号）且同时非缺失；② 相关系数由 B 用 pandas.corr() 计算，C 只负责呈现 |
| 交互组件 | visualMap 映射相关系数（-1 到 1 双色渐变）；Tooltip 显示精确系数 |
| 放置位置 | 大屏第三列下部 |

## 图 6：宁波市行政区房价地图（Map / Geo）

| 项目 | 说明 |
|---|---|
| 图表目的 | 全大屏的特色交互图（必备 Timeline 或地图/词云之一），空间分布一目了然 |
| 内容 | 以宁波各区地图区域着色，颜色深浅 = 平均单价 |
| 所需字段 | 行政区、单价(元/平) 均值；另需**可靠的 geoJSON 行政区边界数据** |
| 清洗要求 | ① 区名必须与 geoJSON 中 name 精确匹配（"海曙区"vs"海曙"）；② geoJSON 数据源未验证前此图暂缓，先用"各区均价条形地图"兜底方案 |
| 交互组件 | visualMap 颜色映射；Tooltip 显示区名+均价+在售房源数 |
| 放置位置 | 大屏中部主视觉位置（最大的一块） |
