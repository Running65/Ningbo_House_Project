## 图 1：各行政区平均单价柱状图（Bar）

| 项目 | 说明 |
|---|---|
| 图表目的 | 回答"宁波哪个区县房价最高/最低"，是全大屏的核心对比图 |
| 横轴（X） | district（行政区），按平均单价降序排列 |
| 纵轴（Y） | unit_price 均值（元/㎡），保留整数 |
| 所需字段 | district、unit_price |
| 清洗要求 | ① 统一区域名称（如"鄞州区"→"鄞州"）；② unit_price 统一为元/㎡数值型（正则去掉"元/平方米"等文本）；③ 剔除 unit_price 缺失或为 0 的记录 |
| 交互组件 | Tooltip 显示均价+房源数；DataZoom 当区县较多时横向缩放 |
| 放置位置 | 大屏左侧第一列，最显眼位置 |

## 图 2：总价区间占比饼图（Pie）

| 项目 | 说明 |
|---|---|
| 图表目的 | 回答"市场上哪种总价的房子最多"，展示房源价格结构 |
| 分组 | total_price 分箱：<100万 / 100-150万 / 150-200万 / 200-300万 / 300-500万 / >500万（分箱边界第 3 周按 B 的数据分布微调） |
| 所需字段 | total_price |
| 清洗要求 | ① total_price 统一为万元数值型；② 剔除缺失值；③ 分箱前用 describe() 检查极端值（如 1 元房源为异常） |
| 交互组件 | Tooltip 显示占比百分比；扇区可点击高亮（selected mode） |
| 放置位置 | 大屏第二列上部 |

## 图 3：面积与单价散点图（Scatter）

| 项目 | 说明 |
|---|---|
| 图表目的 | 回答"是不是面积越大单价越便宜"（学区房/改善房规律） |
| 横轴（X） | area（㎡） |
| 纵轴（Y） | unit_price（元/㎡） |
| 所需字段 | area、unit_price（可选 district 做颜色系列） |
| 清洗要求 | ① area 数值型，剔除 0 或极端值（如 >500㎡ 需核实）；② 与图 1 共用 unit_price 清洗规则 |
| 交互组件 | Tooltip 显示小区名+具体面积单价；visualMap 按单价映射颜色 |
| 放置位置 | 大屏第二列下部 |

## 图 4：各行政区单价箱线图（Boxplot）

| 项目 | 说明 |
|---|---|
| 图表目的 | 展示各区房价的分布和离散程度（均值低不代表没有高端盘） |
| 横轴（X） | district |
| 纵轴（Y） | unit_price 分布（上须、四分位、中位数、下须、离群点） |
| 所需字段 | district、unit_price |
| 清洗要求 | ① 每区样本量须足够（如 ≥30 条），样本太少的区合并或标注；② 离群点保留但可点击 Tooltip 查看 |
| 交互组件 | Tooltip 显示四分位数 |
| 放置位置 | 大屏第三列上部 |

## 图 5：数值变量相关性热力图（Heatmap）

| 项目 | 说明 |
|---|---|
| 图表目的 | 一眼看懂总价、单价、面积之间两两相关性，为筛选模型提供依据 |
| 内容 | total_price × unit_price × area 的 3×3 相关系数矩阵（Pearson） |
| 所需字段 | total_price、unit_price、area |
| 清洗要求 | ① 三个字段均为数值型且同时非缺失；② 相关系数由 B 用 pandas.corr() 计算，C 只负责呈现 |
| 交互组件 | visualMap 映射相关系数（-1 到 1 双色渐变）；Tooltip 显示精确系数 |
| 放置位置 | 大屏第三列下部 |

## 图 6：宁波市行政区房价地图（Map / Geo）

| 项目 | 说明 |
|---|---|
| 图表目的 | 全大屏的特色交互图（必备 Timeline 或地图/词云之一），空间分布一目了然 |
| 内容 | 以宁波各区地图区域着色，颜色深浅 = 平均单价 |
| 所需字段 | district、unit_price 均值；另需**可靠的 geoJSON 行政区边界数据** |
| 清洗要求 | ① 区名必须与 geoJSON 中 name 精确匹配（"海曙区"vs"海曙"）；② geoJSON 数据源未验证前此图暂缓，先用"各区均价条形地图"兜底方案 |
| 交互组件 | visualMap 颜色映射；Tooltip 显示区名+均价+在售房源数 |
| 放置位置 | 大屏中部主视觉位置（最大的一块） |
