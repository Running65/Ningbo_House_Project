## 提示：什么算「排错案例」

只要是「AI 生成的代码/方案出了问题 → 你发现 → 查原因 → 修好」的过程，都算。比如：

- 爬虫字段解析错误（如单价多带「元/平」单位）
- 中文乱码 / 编码问题
- 翻页逻辑不对
- 数据缺失、重复
- Git 冲突解决

每个案例按上面的「现象 → 排查 → 原因 → 修复 → 总结」五步写即可。
