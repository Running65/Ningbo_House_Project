# 协作规范

宁波房产数据分析项目 · 小组协作说明

## 仓库

- 地址：https://github.com/Running65/Ningbo_House_Project
- 默认分支：`main`（只保留合并后的稳定代码）

## 成员与分支

| 成员 | 工作分支 | 说明 |
|---|---|---|
| A | `member-a` | 组长，负责审核与合并 |
| B | `member-b` | |
| C | `member-c` | |

> 每人只在自己的分支上开发，**不要直接向 `main` 提交**。

## 每日工作流程

**开工前（同步最新代码）**

```bash
git checkout member-a      # 换成你自己的分支名
git pull
```

**收工前（提交并推送）**

```bash
git add .
git commit -m "说明这次改了什么"
git push
```

**合并到 main（由组长 A 操作）**

1. B / C 推送后，到 GitHub 发起 Pull Request（`member-x` → `main`）。
2. 组长 A 检查代码，确认没问题后点 **Merge pull request**。
3. 合并完成后，通知大家重新 `git pull`。

## 新成员接入

```bash
git clone https://github.com/Running65/Ningbo_House_Project.git
cd Ningbo_House_Project
pip install -r requirements.txt
python demo/test_libraries.py   # 验证环境
```

## 注意事项

- **不要上传** `.venv`、虚拟环境、账号密码、Cookie、`.env` 等敏感内容（`.gitignore` 已配置好，不要取消忽略）。
- `.idea/`（PyCharm 本地配置）属于个人文件，已被忽略。
- 提交说明写清楚「这次改了什么」，方便别人查看。
- 遇到冲突先和对方沟通，不要直接覆盖别人的代码。
