# 六周进度计划（权威版）

> 依据《宁波市二手房项目_三人分工与六周进度计划.docx》整理

## 项目概况

- **项目名称**：宁波市二手房市场价格分析与可视化研究
- **方向**：C —— 城市二手房市场价格洞察
- **范围**：数据采集 → 数据存储 → 数据清洗与分析 → Pyecharts 可视化大屏 → 报告与答辩
- **暂不做**：模块五 WebSocket 实时数据接入与动态监控

## 成员分工

| 成员 | 角色 | 主要职责 |
|---|---|---|
| A | 项目负责人、数据采集工程师 | 项目统筹；数据源调研；爬虫开发与采集；Git 仓库管理；项目文件整合；立项与答辩材料统筹 |
| B | 数据清洗与分析工程师 | Pandas 探查与清洗；缺失/重复/异常值处理；正则提取；统计分析；性价比筛选；报告分析部分 |
| C | 可视化与前端工程师 | Pyecharts 图表；大屏布局；HTML/CSS；交互组件；页面联调；演示录屏与可视化报告 |

## 硬性指标（验收标准）

| 模块 | 要求 |
|---|---|
| 数据采集 | 第2周 ≥1000 条有效记录、≥6 个有效业务字段；遵守网站规则，合理延时，不高频并发 |
| 数据清洗 | 缺失/重复/异常值有明确规则并在报告中说明；不随意填补朝向等不可靠字段 |
| 可视化 | ≥6 种不同类型图表；顶部 3-4 个 KPI 指标卡；配置 DataZoom/VisualMap/Toolbox/Tooltip |
| AI 协作日志 | 第1周起记录，最终 ≥3 个真实排错案例 |
| Git | 保留真实提交记录，便于核查个人贡献 |

## 每周共同检查点

| 周次 | 共同检查内容 | 必须完成的阶段成果 |
|---|---|---|
| 第1周 | 确认项目方向、数据来源、字段、分工和 Git 仓库 | 立项 PPT；Git 链接；20 条真实测试数据；爬虫 Demo |
| 第2周 | 检查数据数量、字段完整性和爬虫稳定性 | spider.py；raw_data.csv；字段说明 |
| 第3周 | 检查清洗逻辑、数据质量和初步分析结果 | clean.py；clean_data.csv；EDA 分析摘要 |
| 第4周 | 检查至少 6 种图表、KPI 指标卡和交互功能 | 大屏初版 HTML；核心图表代码；页面截图 |
| 第5周 | 检查项目完整运行、数据与图表一致性 | 稳定版代码；README 初稿；2-3 分钟演示视频初稿 |
| 第6周 | 检查报告、PPT、AI 协作日志、演示视频和代码 | 最终压缩包；PDF 报告；AI 协作日志；答辩 PPT；演示视频 |

## 每周时间安排

| 时间 | 工作安排 | 参与人员 |
|---|---|---|
| 周一 | 明确本周任务、负责人和截止时间 | 三人共同 |
| 周二~周三 | 各自完成代码/数据/页面工作 | 各自独立 |
| 周四 | 展示阶段成果，检查进度并解决问题 | 三人共同 |
| 周五 | 模块整合与联调，检查数据接口和运行流程 | 三人共同 |
| 周末 | 验收、整理文件、更新 Git、课程平台打卡提交 | 成员 A 统筹 |

## 注意事项

1. **AI 协作日志**：从第1周开始记录关键 Prompt、AI 生成代码的问题/Bug、人工排查与修复思路，最终整理 ≥3 个真实排错案例。按成员分开维护，如 [成员A的日志](AI协作日志_成员A.md)。
2. **代码理解**：每位成员都应理解项目整体流程和自己负责的核心代码。
3. **可视化图表**：行政区房价柱状图、总价区间饼图、面积与单价散点图、房价箱线图、相关性热力图、宁波行政区房价地图。
